# ps5-fanContrl

[English](README.md) | **简体中文**

基于配置文件的 PS5 风扇控制器，支持自定义风扇加速阈值（目标温度）与刷新检测时间间隔。

---

## 🌟 核心特性

* **安全的自动伺服温控**  
  通过严格的 **“读取 -> 修改 -> 写入 -> 回读校验”**（`GET -> Modify -> SET -> Readback`）流程修改 `/dev/icc_fan` 的目标温度字节（第 5 字节），完整保留原厂风扇校准曲线与南桥高温保护（Fail-safe）机制。

* **无死角防重置守护**  
  实时监测系统状态切换（启动游戏、挂起切回主界面、休眠唤醒等）。一旦系统（`SceShellCore`）切换模式并将风扇策略重置回出厂默认值，守护进程会在下一个检测周期内自动重新应用自定义阈值，且不会重复写入或刷屏弹窗。

* **配置文件热重载**  
  支持通过 U 盘或主机内置存储修改配置文件，无需重启 Payload 即可动态热更新目标温度、刷新间隔和状态通知开关。

* **硬件熔断保护与动态传感器探测**  
  动态适配不同批次主板的 SoC 温度传感器数量并取最高温度显示；若底层硬件读写连续异常达到上限，进程会自动安全退出并将散热控制权完整交还给原厂系统。

## ⚙️ 配置文件说明

创建一个名为 `fan_control.ini` 的文件，并放置在以下任意路径（按优先级从高到低读取）：

1. **主机内置存储（最高优先级）：** `/data/fan_control.ini`
2. **U 盘根目录（备用路径）：** `/mnt/usb0/fan_control.ini` ~ `/mnt/usb7/fan_control.ini`

### `fan_control.ini` 配置示例

```ini
# 目标温度阈值，单位摄氏度（有效范围：30 - 90，默认值：80）
target_temperature=80

# 状态轮询与刷新检测的时间间隔，单位秒（有效范围：1 - 3600，默认值：15）
interval=15

# 当目标温度首次生效或系统重置后重新覆写时，是否弹出系统提示（1 = 开启，0 = 关闭）
show_status=1
```

> **注意：** 若未检测到任何配置文件，程序将以默认参数运行（`target_temperature=70`、`interval=5`、`show_status=0`）；若检测到配置文件损坏或参数越界，程序会安全退出并交由原厂温控接管。

## 🛠️ 编译指南

本项目基于 [ps5-payload-sdk](https://github.com) 工具链构建。

```bash
# 如 SDK 未安装在默认目录，请先指定环境变量路径
export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk

# 编译生成 ELF 文件
make clean && make
```

编译生成的 `ps5-fancontrl.elf` 可通过任意 Payload 加载器（如 `elfldr`、`etaHEN` 或网络端口推送）发送至 PS5 运行。
